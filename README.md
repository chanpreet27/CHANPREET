# Chanpreet Singh — Personal Portfolio

> Personal portfolio website of Chanpreet Singh — AI Researcher & Product Builder.  
> First-year B.Sc. (Hons.) Computer Science student at Sri Guru Gobind Singh College of Commerce, University of Delhi.

## 🚀 Live Demo
- **Live Website:** [https://chanpreet-portfolio-ten.vercel.app](https://chanpreet-portfolio-ten.vercel.app)

## 🛠️ Tech Stack
- **Frontend:** Vanilla HTML5, Modern CSS3, JavaScript (ES6+)
- **Graphics & 3D:** Three.js (interactive dotted wave particle canvas)
- **Styling:** Custom dark cyberpunk/minimal aesthetic with Kanit & Space Mono typography
- **Hosting:** Vercel

## 📂 Project Structure
- `index.html` — Main website markup
- `css/` — Stylesheets (`styles.css`, `fonts.css`)
- `js/` — Custom animations, navbar, cursor, typed title, and Three.js canvas (`script-1.js`, `script-2.js`, `three.min.js`)
- `assets/` — Offline fonts (`fonts/`)
